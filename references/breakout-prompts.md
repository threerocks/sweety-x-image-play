# 主体出框通用提示词

以下分为选主体、生成蒙版、制作成品三个阶段。变量根据当前原图填写，不能把样例里的手、猫、石头写成每次都适用的固定目标。默认 20 张、每张 80 px；用户指定的数量和宽度覆盖默认值。

## 1. 看图选主体

```text
分析这张图，确定“应该让什么东西突破背景条框”。
用户明确重点：{用户指定；未指定时自行判断}。

选择最能说明画面趣味或主题的语义主角。接触、握持、承托、遮挡或靠近主角的物体，不因此自动成为主角。不要只按面积最大、离镜头最近或轮廓连通来选。

给出简短结果：
- target：要出框的具体对象或可见部位。
- exclude：容易被误并入的对象；它们留在原图里，但参与背景分条。
- occlusion：哪些非目标物体挡住了目标；保留原有遮挡，只选实际可见表面。
- preserve：需要另行保护的文字、标志等区域，与 target 分开。
- reason：一句话解释为什么突出这个目标。

不要把所有前景一起抠出来。用户明确要求多个对象共同出框时，才将它们列为组合目标。目标明确就直接继续，不必逐次询问确认。
```

## 2. 生成主角蒙版

```text
输入是待处理原图。输出与原图完整画布严格配准的灰度蒙版，不是新插画。

唯一需要选出的目标：{target}。
必须排除：{exclude}。
遮挡关系：{occlusion}。

纯白只覆盖目标实际可见的表面。所有非目标区域为纯黑，包括与目标接触、抓握、承托或遮挡目标的其他物体。非目标物体挡住目标时，该遮挡区域保持黑色，不补画背后不可见的目标。

保持目标位置、大小、比例、朝向及原图边界。不要移动居中、扩大到邻接物、重构轮廓或补全被挡住的部分。目标内部为实心白色，不绘制纹理、阴影、五官或分隔线；灰色仅用于必要的边缘抗锯齿。空洞依据原图真实可见区域决定。

本阶段不处理标题或装饰保护层，不添加条框、文字或颜色。完成后用于叠回原图检查，只有目标通过检查才能继续。
```

## 3. 合成与等宽导出

```text
用原图与已验收的主角蒙版制作主体出框效果。
主角：{target}；排除对象：{exclude}；另行保护的信息区域：{preserve}。

只让主角覆盖图内的透明条缝。其他物体按背景统一分条，不删除、不重绘，不为连接主角而自动把手臂、叶片、桌子等纳入突出区域。若需保护文字，用独立保护层处理，不扩大主角定义。

输出 {count=20} 张独立透明 PNG，每张严格 {slice_width=80} 像素宽，全部同高；总画布宽度为 count × slice_width。母图与蒙版按同一比例准备到该总宽，保持完整构图，不挤压主体、不单独拉伸各切片。

背景条框使用统一节距、统一条宽、统一间距和圆角。默认每 80 px 包含 72 px 图像条和 8 px 透明缝。不要为迁就主体大小生成宽主图加窄侧条，不擅自改变附件数量或宽度。

精确像素由导出工具执行和检查，不依赖生成模型承诺。检查目标选区、每张尺寸、顺序、重组、透明度、浅深底预览及真实图间距下的效果。

真实附件间距无法被图片覆盖；等宽切片切到主体时如实说明。交付独立文件、尺寸清单和模拟预览，不把整幅预览当成上传附件。
```

## 用于复核通用性的反例

- 手拿石头，目标是石头：白色不能包含手、戒指或手臂；拇指挡住的石头区域不能被补白。
- 猫藏在植物里，目标是猫：邻近/遮挡的叶片不能因“连接自然”被自动加入；目标为叶片时判断反过来。
- 目标是手势或整个人：不能机械执行“所有手都排除”。
- 主体偏左、偏右或占幅很大：改变选区与构图判断，不改变默认 20 张等宽规格。
- 海报含标题和缩略图：标题保护与主角选区分离，不把缩略图中的同类物体一并抠出。

这些是语义验收情境，不代表已经对所有新图进行了生成测试。

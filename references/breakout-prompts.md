# 多图主体突出：贯穿线提示词

默认 20 张等宽、每张 80 px。当前默认是贯穿线版本：保留的线从画面顶部贯穿到底部。只有用户明确要求传统局部出框时，才让主体覆盖图内条缝。两套规则不能混用。

## 1. 看图确定主体与线的布局

```text
分析原图。用户指定的重点是：{用户重点；未指定时根据图像判断}。

列出：
- target：唯一需要突出的语义主角。
- exclude：与它接触、握持、承托、遮挡或相邻，但不属于主角的对象。
- occlusion：原图真实遮挡关系。
- preserve：需要保留内容的文字、标志或版式区域。
- line_layout：整幅画面统一的竖线位置、宽度、间距。

接触不等于同一个对象。石头为主角时，不自动把手、手臂、戒指纳入主角；猫为主角时，不自动把叶片、花盆、墙面纳入主角。不得补画原图不可见的部位。

线的保留或取消以整条为单位。默认采用统一节距的完整竖线，不因主体蒙版自动取消一大片线。确需避让时只能调整整条线的位置或取消整条，必须保持统一布局并说明原因；不能只擦掉中间一段。20 张附件的宽度始终固定，不随线的位置或主体大小变化。
```

## 2. 制作母图

```text
输入为原图。主角：{target}；非主角：{exclude}；遮挡关系：{occlusion}；信息区域：{preserve}。

保留原图主体身份、姿态、真实遮挡及文字内容，不补全被遮住的目标，不把接触主角的对象并入主角。需要分析选区时，主角蒙版只包含实际可见表面；它不用于覆盖或擦除竖线。

核心约束：有线就必须是一条完整的线。每条保留的竖线从整幅画面的最上边延伸到最下边，横坐标固定，宽度与透明度一致。不能在画面内部起笔、收笔、分叉、变细、消失后重现；不能留下短线、孤立线段或局部缺口。

线的连续性优先于局部出框。将完整竖线层放在最终可见层；人物、物体、前后遮挡和文字保护区都不能盖住它。若用透明条缝表达线，则该缝在全高范围都保持透明，不能由主体或标题补回像素。不要同时生成有色描边和透明条缝两套线。

石头例：经过拇指的线不能只留下拇指上的一小截；它必须继续穿过同列的石头及其他区域，连接到画面顶底。拇指仍然不是石头。
海报例：线必须穿过顶部留白、标题区域、猫身和下方墙面，不能从 BLOOM 标题下沿才开始，也不能到猫身停止。保护文字是保留其内容，不是用完整矩形盖掉竖线。

突出主角依靠画面构图与原有主体背景对比；只有用户允许改变原图时才额外调整背景明暗或色彩。不得为获得出框错觉而违反贯穿线规则，也不默认删除主体附近的全部竖线。

保持整张图的比例。先完成统一母图，最后切片，不分别生成相邻图片。
```

## 3. 等宽导出与验收

```text
输出 {count=20} 张独立 PNG，每张严格 {slice_width=80} 像素宽，全部同高；总画布宽度为 count × slice_width。先将完整母图等比准备到该总宽，不单独拉伸切片，不让末片承担余数。

全套使用统一线宽与节距；透明条缝默认每 80 px 为 72 px 图像区域加 8 px 透明缝。保留的每一条缝都贯穿全高。不得将原图主体蒙版或文字保护层再次叠到条缝上。

逐线验收：沿每条线从最顶端追踪到最底端，检查横坐标、宽度和透明度。拇指、手指、叶片、猫耳、身体边界、标题上下沿及画中画边界都要检查。任何一处内部断线、孤立短线或中途开始的线都判为不合格，不因主体选对、20 张等宽或像素重组通过而放行。

再检查每张尺寸、顺序、重组、透明度、浅深底预览。真实附件间距单独模拟，不能把平台间距当作图片内部断线的补救。交付独立文件、尺寸清单和模拟预览。
```

## 执行路径

本规则先制作全高线母图，再用 `panorama` 精确切成 20 张等宽图片。现有 `breakout` 合成器会用主体蒙版局部覆盖条缝，属于传统局部出框实现，不适用于贯穿线要求；不能只修改提示词却继续调用该合成路径。不要向现有脚本传入未实现的 line_policy 等参数。

## 反例与边界

- 石头选区正确，但拇指上出现孤立短线：失败。
- 猫和标题完整，但线只在标题下方、猫身以外出现：失败。
- 20 张都等宽，但线中途断开：失败。
- 通过扩大蒙版把手、叶片并入主体来抹掉短线：失败。
- 为保护主体而自动取消它横向覆盖的全部竖线：不作为默认解决办法。
- 全高竖线会穿过主体，传统“主体盖住线”的出框错觉因此减弱；不能宣称两者已同时实现。

这些是提示词与验收规则。本次调整没有生成新图，不能视作视觉复测通过。

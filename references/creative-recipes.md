# 创意与生成模板

## independent：让物体本身适合窄条

提示词基底：一张图仅一个主体，正面视角、垂直居中、轴线笔直、纯净统一背景、全物体可见。明确颜色、材质和关键辨识部位。禁止多主体拼图。上下端具有自然比例，中间是可延长且宽度稳定的线身。

适合：充电线、彩铅、竹子、蜡烛、香、拉链。40 像素宽时不放微小文字、复杂人物或横向枝叶。主体可占约 30–36 像素宽；这是设计建议，不要将物体宽度和文件宽度混为一谈。白底模式换成深色背景前重新观察 X 深浅主题下的边界。

以充电线为例：上接头和下接头等比缩放，stretch_band 仅选中间光滑线身。竹节或蜡滴不属于均匀可伸展区域；机械拉伸会使节点变粗长，需选多个平滑段或让模型先形成更长的母图。本版工具只支持一个显式伸展段；复杂多段需先用图像工具处理，不能假称已自动解决。

## panorama：整体构图先成立

先声明总构图与切片数：例如母图宽 2800、高 2048，20 个 140 像素宽切片。生成模型若返回其他尺寸，先检查构图，再选择 contain 或 cover；工具不会静默挤压到指定比例。

提示词基底：一幅完整连续场景，左右有明确视觉关系，一条可识别的连接物贯穿，整体照明和背景一致。画面将被竖切成 20 条，不画切割线、不画白边、不画编号。重要五官和文字不跨关键切缝。首屏只显示左侧一部分，因此左端必须能吸引并提示右侧尚有内容。

原创例子：左边小机器人递出一根发光电缆，右边小植物被点亮；长卷山水中一条河从左侧村庄通向右侧月亮；两只猫隔着整幅画拉同一根毛线。

视觉接缝比“每一张都漂亮”更重要。图间 4–8 CSS 像素是可调模拟参数，不是保证的平台规格。可预览零间隙验证母图，又以有间隙视图检查辨识度。

## reveal：滑动必须有终点

先写三句话：首屏看到什么；为何愿意继续滑；尾屏得到什么。第二条参考帖的终点是摸头，不只是无限拖长。

首/中/尾提示词共享：同一画布、同一背景、同一连接线中心 y、同一粗细、同一色值、同一光线；连接物触达对应左右边缘，边缘处无阴影渐变、无漂浮断口。让模型参考已定稿首帧，再生成中段与尾帧，必要时修正接缝。几何完全一致的桥接部分优先复用同一段像素。

低成本方案：生成 3 个资产，导出“首 + 中段重复 N-2 次 + 尾”。有复杂沿途剧情时，按顺序用 N 个 assets，不重复桥接。长中段可故意拖延制造笑点，但默认不要把所有主题都拉满 20 张。

原创例子：小猫伸出长尾巴，末尾勾住一杯奶茶；机器人递出长长充电线，终点是一盆会发光的小花；纸飞机的轨迹横穿多图，最后落在收信人的手中。

验收首、中、尾，尤其首→中、中→中、中→尾三类连接。重复的纯色背景可能让整幅平均误差很小，即使细线错位；必须目视检查连接物，不能只信自动误差数值。

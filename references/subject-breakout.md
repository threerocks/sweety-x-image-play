# 主体出框：只突出语义主角

当前默认要求保留下来的竖线全高贯穿，详见 [贯穿线提示词](breakout-prompts.md)。主体与文字不能局部遮线；先制作全高线母图，再走 `panorama` 切片。下述传统出框规则只在用户明确要求主体覆盖条缝时使用，不能与贯穿线要求混用。

## 传统局部出框（显式选择）

传统出框目标是让选中的物体或角色覆盖背景条缝。动态判断用于选择主角和轮廓；连续切片与主体出框默认交付 20 张等宽图片，不随主体占幅分配附件宽度。

## 主角选择与排除

先明确用户希望观众注意什么。用户指定对象优先；未指定时选最能解释这张图趣味、动作或主题的单一语义目标，不能仅按面积、最近距离或连通轮廓选择。用户明确要求组合主体时可以选择组合。

接触、抓握、承托、遮挡和空间邻近均不自动构成同一个主角。分别列出 `target`、`exclude`、`preserve`：target 是跨越图内条缝的主角；exclude 是不参与出框但仍留在原图中的其他对象；preserve 是文字、标志等单独需要保护的信息区域。

| 图像与目标 | 出框对象 | 不自动带出的对象 |
|---|---|---|
| 手拿形状特别的石头，突出石头 | 可见石头轮廓 | 手、手臂、戒指、地面 |
| 手持饮料，突出饮料 | 杯身及其自身部件 | 手、人物、桌面 |
| 猫在叶片间探头，突出猫 | 猫的可见部分或用户指定部位 | 遮挡猫的叶片、花盆、柜子 |
| 突出整个人物 | 该人物，包括属于此目标的可见肢体 | 邻近的人、道具、家具 |
| 海报里的猫 | 主图中的猫 | 标题、缩略图里的猫、花朵、墙面；文字另作保护 |

不要把“排除手”写成所有图像的硬规则；当目标本身是手势时，手就是主角。通用判断是目标边界，而非具体物体黑名单。

## 遮挡和保真

蒙版只标记目标在原图中实际可见的表面。例如拇指遮在石头前面，拇指仍为黑色，不补画被挡住的石头，不删掉手，不生成一块悬空的新石头。黑色只意味着该位置参与背景条缝，不意味着删除其全部原图像素。

将主角蒙版与原图叠加检查：不能混入承托物，不能用矩形代替轮廓，不能因相邻叶片破碎而把整片叶子自动升级成主角。细边修正应修选区，不改变用户选题。需要保护文字时另建保护层；语义主角蒙版先单独验收，再与文字保护层合并为导出用保留蒙版。文字保护不代表它属于主角，也不能消除真实附件切口。

具体可复用提示词见 [通用提示词](breakout-prompts.md)。蒙版生成后检查位置、比例、边缘和灰度；原图颜色纹理作为固定层，不能用生成模型重绘主体代替保真合成。

## 固定规格与两个不同的缝

- 默认数量 **20 张**，单张宽度 **80 px**（可配置）；总宽 **1600 px**。根据总宽等比准备整张母图，蒙版做同样的几何变换；高度按原比例计算，所有切片同高。不把每片单独拉伸，不让最后一片吃余数，不擅自裁去主体。
- 默认背景条框使用统一节距、统一条宽、统一间距和圆角。默认 80 px 节距内 72 px 图像条 + 8 px 透明缝。不因主体位置把两侧做成疏密不同的条。
- **图内透明条缝**可以被主角像素覆盖，形成出框错觉。
- **真实附件间距**由 X 控制。20 张等宽切片可能切过主体，合成前景无法覆盖跨附件的界面缝。不能承诺等宽附件同时实现平台缝完全消失；预览必须保留实际间距模拟，并注明未实机验证的范围。
- `layout: uniform` 为默认；历史 `layout: adaptive` 宽主图方案只在用户明确选择不等宽后使用，不能因主体较宽而自动回退。若用户要求主体绝不被真实切口穿过，显式设置 `allow_subject_cuts: false` 检测冲突，并讨论数量、构图或单图展示的取舍；不能偷偷改宽度。

## 验收重点

先验主角：目标是否被独立选出，是否混入被排除对象；再验文件：20 张、每张固定宽度、全部同高、重组无遗漏；最后验视觉：图内条宽与间距一致、前景边缘自然、浅深底无杂边、真实间距下仍可辨识。`foreground_pixels_preserved` 只能证明白色保留区域未被重绘，不能证明选对了主角。
